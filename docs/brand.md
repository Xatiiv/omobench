# OmoBench visual identity

The website uses plum and chartreuse. This is a website-only refresh; the local panel and Windows installer are separate surfaces.

| Role | Colour |
| --- | --- |
| Canvas | `#160F1C` |
| Plum surface | `#211326` |
| O / secondary accent | `#C77DFF` |
| MO / primary action | `#C5F542` |
| Bench / main text | `#FAF6EB` |
| Secondary text | `#BCAEC5` |

The display wordmark is **OMOBench**, split O / MO / Bench. The product name in prose and accessible labels stays **OmoBench**. The header uses live text and a vector mark, not an image of lettering.

`public/brand/` contains original, transparent, self-contained SVGs: mark, hero hardware drawing, hardware, compare and evidence illustrations. `public/favicon.svg` uses a plum tile for contrast on both light and dark browser chrome. No external fonts, embedded raster data or scripts are required. Artwork is decorative when accompanied by its heading: use empty alt text. Do not present illustration bars as benchmark results.

Use chartreuse for actions and selected emphasis; purple for secondary emphasis. Keep amber warnings and red errors semantically distinct. Never rely on colour alone for status or chart series. Buttons use plum text on chartreuse, not white. Keep outlines, labelled chart series and reduced-motion support.

Reuse the assets rather than adding stock photos, robots, glows, gradients or animated graphs. The registry and actual measurements remain the main content. Do not change metrics, comparison rules, model eligibility, release metadata or evidence as part of styling.
