Installation readiness

The first release targets Windows. The current runner requires a supported Linux, macOS, or WSL2 environment. Native Windows GPU execution has not been qualified by this milestone.

The application will show compatibility before downloading a runtime. An incompatible GPU will never silently switch your test to CPU.
