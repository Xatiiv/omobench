OmoBench companion, local link test

This file is a plain local page, not the OmoBench website. It exists so the registered omobench://open handler can be tested without running the site and without typing a command.

Open OmoBench

Expected: Windows starts the companion (it may ask once which app to use), the companion starts the panel in your configured WSL environment, and your browser opens the guided benchmark page. Clicking again reuses the same panel rather than starting a second one.

Nothing happened? The companion is probably not registered yet, open it and use Setup… → Save and register omobench://. The companion window itself also has an Open panel button that does the same thing without any link.

This page cannot tell whether the panel opened: it has no access to it. Check the companion window, which shows starting, ready, or failed.
