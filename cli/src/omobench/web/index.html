Measure your hardware.

OmoBench runs a fixed workload against a model server and records what your machine did with it. The model is the load; the hardware is the subject.

                        What this screen is for

                        Save local report, above, needs none of this: it exports what this machine measured, for any model, with no sign-in. This screen prepares a community submission, which also needs the model's identity and eligibility, the exact weights you ran, the machine that served them, and a run that met the profile's acceptance thresholds. Packaging uses the existing CLI and registry validator, and nothing here relaxes either.

                        Model identity and licence Needed to share publicly

                        Which model is this?

                        Two different things, kept apart. Your server answers to whatever identifier it was configured with; the model has its own canonical identity. Nothing maps one to the other without you choosing it. A model not on the curated list can still be benchmarked, saved and submitted — it then carries its own licence and downloadability instead.

                            Propose this model for the catalog

                            Optional. A proposal asks for this model to be added to the curated list. It is not needed to submit this result — declaring the model's own licence and downloadability does that. A reviewer sees a proposal and the evidence together, and merging the result does not add the model either way.

                                    Permissions and privacy
                
                                    GitHub's public_repo permission allows writing to public repositories. It does not request access to private repositories. OmoBench uses it for the public fork and submission you review below.
                                    
                
                                    Your GitHub credential stays in this panel process's memory, for at most eight hours. Signing out or stopping the panel forgets it locally. It does not revoke the app on GitHub.
