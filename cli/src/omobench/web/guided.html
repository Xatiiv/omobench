    Your performance report

    Your measurements are saved on this machine. Save local report exports them as a local record, for any model, with no publication metadata and no sign-in. It carries the context a comparison needs in three groups: the workload definition (profile and its bytes, request format, concurrency, token targets), the model configuration (identity, revision, quantization, tokenizer) and the execution configuration (hardware, your CPU/GPU declaration, serving runtime). Comparing CPU against GPU, or one machine against another, on an otherwise identical workload is exactly the comparison this is for. Preparing a community submission is a separate step with its own requirements.

        Permissions and privacy

        GitHub's public_repo permission allows writing to public repositories. It does not request access to private repositories. OmoBench uses it for the public fork and submission you review below.

        Your GitHub credential stays in this panel process's memory, for at most eight hours. Signing out or stopping the panel forgets it locally. It does not revoke the app on GitHub.
