GUIDED CPU SETUP

Set up a reviewed CPU model, step by step.

This guided path downloads and verifies one reviewed model + runtime recipe, then runs the same, unchanged benchmark engine as the advanced panel. It is a development milestone, not an installer: it does not touch system packages, and this page only runs the CPU benchmark — it does not package or submit results itself. The evidence it produces is a normal local run, and CPU and GPU results are both eligible for packaging and submission from the advanced panel or the omobench package CLI command. Use the advanced panel to connect to a model server you already run yourself, or to package a run from this page.
